# Unemployment Analysis with Python

**CodeAlpha Data Science Internship — Task 2**

## Project Overview
This project analyzes unemployment trends in India using Python. It explores changes in unemployment rates over time, including the period around the COVID-19 pandemic.

## Dataset
The project uses the Unemployment in India dataset from Kaggle.

Dataset: https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india

## Tools and Libraries
- Python
- Pandas
- Matplotlib

## Methodology
1. Loaded and cleaned the unemployment dataset.
2. Explored unemployment rates over time.
3. Created visualizations to identify trends.
4. Compared average unemployment rates before and during the COVID-19 period.

## Analysis and Results
The analysis includes:
- Unemployment trends over time
- Comparison of average unemployment rates across two periods
- Visualizations of unemployment patterns

The results show an increase in the average unemployment rate during the period beginning in March 2020 compared with the earlier period.

## How to Run
Install the required libraries:

```bash
pip install pandas matplotlib
```

Run the Python script:

```bash
python unemployment_analysis.py
```
