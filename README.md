# Unemployment Analysis with Python

**CodeAlpha Data Science Internship — Task 2**

## Project Overview

This project analyzes unemployment trends in India using Python. It explores changes in unemployment rates over time, including the period around the COVID-19 pandemic, and compares average unemployment rates across different states and regions.

## Dataset

The project uses the Unemployment in India dataset from Kaggle.

[Unemployment in India — Kaggle Dataset](https://www.kaggle.com/datasets/gokulrajkmv/unemployment-in-india)

The dataset contains information about unemployment rates across different regions and time periods.

## Tools and Libraries

- Python
- Pandas
- Matplotlib

## Methodology

1. Loaded and explored the unemployment dataset.
2. Cleaned and prepared the data for analysis.
3. Analyzed unemployment rates over time.
4. Compared average unemployment rates across states and regions.
5. Created visualizations to identify unemployment trends and patterns.

## Visualizations

### 1. Overall Trend of Unemployment Rate in India

A line graph showing changes in the mean estimated unemployment rate over time.

The graph shows a sharp increase around April–May 2020, followed by a decline in the subsequent months.

### 2. Average Unemployment Rate by State/Region

A horizontal bar chart comparing average estimated unemployment rates across different states and regions.

The graph highlights substantial variation in unemployment rates across regions.

## Key Findings

- Unemployment rates increased sharply around April–May 2020.
- The unemployment rate declined after its peak in the following months.
- Unemployment rates varied considerably across states and regions.
